# 📒 PromptLedger - Track, Test, and Improve Your AI Prompts

---

## 🚀 What Is PromptLedger?

PromptLedger is a friendly tool that helps you keep track of the instructions you give to AI programs (called "prompts"). If you have ever used ChatGPT, Claude, or similar AI tools, you know that sometimes changing a few words in your question can change the answer completely. PromptLedger lets you save different versions of your prompts, compare them side by side, and see which ones work best. Think of it as a notebook that remembers everything you tried and shows you the results.

## 🧩 Understanding the Details (For the Curious)

Behind the friendly interface, PromptLedger uses two powerful tools working together. The main engine is written in Python, a popular programming language known for being clean and reliable. It handles all the heavy lifting like storing your templates and scoring responses. There is also a companion tool written in Go, which is like a super-fast helper that makes certain tasks quicker, such as running comparisons at high speed.

The program is built around the idea of **reproducibility**. That means every time you run a test, you get the same results if you use the same prompts. This is very important for making fair decisions about which prompts are better.

People who work with machine learning or artificial intelligence professionally will appreciate features like **benchmarking** and **diffable experiment reports**. In simple terms, benchmarking means measuring how good something is in a standard way. A diffable report is one that shows exactly what changed between versions, like a highlighted document showing added and removed words.
